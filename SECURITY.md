# Security and responsible operation

Report security issues privately to the repository owner rather than opening a public issue with exploit details.

Never commit API keys, cookies, wallet seeds, private messages, personal data, or raw customer exports. Use a secret manager and least-privilege service accounts.

Agents must stop on authentication changes, rate-limit warnings, unexpected financial actions, policy uncertainty, or a material mismatch between the requested task and the skill file. Human approval is required for wagers, purchases, payouts, account creation, and publication of sensitive or adult material.

“Zero-touch” means the routine workflow can run without manual labor; it does not remove safety gates or make an operator immune from responsibility.
