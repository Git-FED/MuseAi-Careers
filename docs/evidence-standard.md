# Evidence standard

Every performance claim needs a source and a label.

- **Observed:** raw export/log/screenshot is attached or linked.
- **Reported:** operator statement, awaiting independent check.
- **Projected:** arithmetic or scenario.
- **Pending:** not executed.

Evidence should include date, timezone, method version, input source, output, cost, and limitations. Redact secrets and personal information. Never turn a small sample into a guaranteed rate.
