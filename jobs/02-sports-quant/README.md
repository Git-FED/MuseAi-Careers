# 02 — Multi-Sport Quant Desk

**Job:** Run an operator-supplied formula against permitted sports data and maintain a paper record.

**Agent does:** collects inputs, applies the unchanged method, shows arithmetic, and logs outcomes.

**Human does:** owns the method, evaluates the output, controls bankroll, and places any wager.

**Ceiling:** no picks, stake advice, sportsbook access, wallet access, win-rate promise, or future-return claim.
