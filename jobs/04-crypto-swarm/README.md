# 04 — Crypto Swarm / Micro-Yield Experiment

**Status:** Fleet provisioned / pending execution.

The system may work technically and still work very poorly economically. The brief's 4–8 cents/day figure is an estimate, not a measured result. No proof of a running miner, wallet, pool, payout, or net-positive P&L is included in this repository.

## Measurement first

Use a single compliant test deployment. Record hashrate, shares, uptime, payout threshold, provider cost, pool fee, and net result. Do not scale until the first run proves the economics and the provider/pool terms permit it.

## Human boundary

The operator authorizes infrastructure, chooses the pool/wallet, reviews costs, and may stop the process. The agent may monitor a bounded worker and report status; it must not create accounts, evade quotas, or move funds.
