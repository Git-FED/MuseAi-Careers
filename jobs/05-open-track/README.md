# 05 — Open Track

Propose a new job with:

1. job title and user;
2. what the agent does;
3. what remains human;
4. explicit refusals;
5. cost and platform risks;
6. at least ten draft evaluation cases;
7. evidence format and a rollback/stop rule.

A proposal is not a live track. It becomes active only after the owner supplies a versioned skill, test set, and evidence plan.
