# Contributing

Keep contributions evidence-first and bounded.

## Before opening a pull request

- Label claims as observed, reported, projected, or pending.
- Add a dated evidence note for new performance claims.
- State what remains human-controlled.
- Add refusal behavior and a rollback path to new skills.
- Do not add secrets, private account data, scraped personal data, or instructions that bypass platform safeguards.

## Track acceptance

A new track needs a job description, owner, human boundary, risk review, at least ten draft evaluation cases, and a plan for a re-runnable evidence record. A track cannot be labeled certified from a forecast alone.
